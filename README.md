# bokalwina-feed

Автообновляемый YML-фид для Яндекс Директа магазина bokalwina.ru (Tilda).

- Источник: `https://bokalwina.ru/feed-fb.csv` (штатный фид Тильды, включается в Настройки каталога → Дополнительно).
- Сборка: `build_feed.py`, запускается GitHub Actions каждый час.
- Результат: `docs/bokalwina.yml`, отдаётся через GitHub Pages.

Правила: товары без цены/картинки не попадают в фид; категория и vendor определяются по бренду в названии.
